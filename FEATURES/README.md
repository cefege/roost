# Roost features — unified inventory

Canonical registry of the v3 release boundary and honestly unavailable
surfaces. Named live source is the implementation authority; every row below
was checked against it on 2026-10-06.

## Status legend

- **SHIPPED:** included in the public self-hosted v3 release (`v3.*` tags),
  wired end to end and reachable from the UI or CLI
- **PREF-ONLY:** a visible control exists, but nothing acts on it yet
- **DEFERRED:** consciously postponed; the row names what is missing
- **DELETED:** superseded or based on a wrong premise
