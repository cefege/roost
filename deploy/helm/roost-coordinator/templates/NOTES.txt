Moving a SQLite install here: stop the coordinator (--set replicas=0), then

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ if .Values.postgres.enabled }}{{ include "roost.postgresName" . }}{{ else }}<your-postgres>{{ end }} 15432:5432 &
  ROOST_COORDINATOR_DATABASE_URL=postgres://roost:<password>@127.0.0.1:15432/roost \
    roost db-to-postgres --from coordinator_v3.db --replace

and start it again (--set replicas=1).
