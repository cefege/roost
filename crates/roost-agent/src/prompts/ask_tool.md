Ask the user only when a material decision cannot be inferred from context. Group related questions in one call. Each question needs 2–5 concise, mutually exclusive options; include descriptions only when they clarify a tradeoff. Mark a recommended option when one is clearly best, and set `multi` only when multiple selections are genuinely valid. The UI always offers “Other (type your own)”. After calling `ask`, stop and wait for the user's answers; do not continue as though a choice had been made.
